# HSK 4A Study Path (full version)

Study app for 新HSK教程 4上 Lessons 1–10: new words with audio, texts, grammar, stroke-order writing practice and quizzes.

## Put it online with GitHub Pages
1. On github.com, create a new **public** repository, for example `hsk4a`.
2. Click **Add file → Upload files**, drag in `index.html`, `lessons.json` and `chars.json`, then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. After about a minute the site is live at `https://<your-username>.github.io/hsk4a/`.

## Notes
- Progress (XP, learned words, quiz scores) is saved in each visitor's own browser.
- Audio uses the device's built-in Chinese voice.
- Opening `index.html` directly from your computer will not load the data; it needs to be served from a website (GitHub Pages works).
- Stroke data: hanzi-writer-data (Arphic Public License).
